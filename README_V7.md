# JJUN Display v7.0 — staging/production package

이 폴더는 새 GitHub Pages 저장소 `sparta-display-next`에 그대로 올릴 수 있습니다.

## 권장 운영 구조
- 운영: https://etooskj.github.io/sparta-display
- 개발: https://etooskj.github.io/sparta-display-next

## 새 GitHub 저장소 생성
1. GitHub에서 New repository → `sparta-display-next` 생성
2. 이 폴더의 `index.html` 업로드/커밋
3. Settings → Pages → Deploy from a branch → main / root
4. ERP → JJUN Central → 화면 관제에서 개발 URL 확인
5. 학습실 테스트 화면: `?screen=studyroom-test&group=test`
6. 검증 후 운영 저장소 `sparta-display`에 동일 index.html 반영
