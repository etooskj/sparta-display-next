# 쭌에듀 × 스파르타 Display V8.2

## 변경사항
- 다크테마에서 방패 배경 로고를 밝은 워터마크로 표시해 시인성 개선
- 방패 로고 크기 확대
- 기본 전광판 그룹은 `studyroom` 유지
- ERP/JJUN Central 공지 수신 경로 강화
  - `display/currentNotice`
  - `display/currentBroadcast`
  - `jjunCentral/currentNotice`
- 예약 공지는 기존 `display/notices` 경로 유지

## GitHub 적용
`index.html`을 `sparta-display-next` 저장소의 기존 `index.html`에 덮어쓰기 후 Commit 합니다.
